# Handwritten Character Recognition

## About the Project

This project recognizes handwritten digits from 0 to 9 using Machine Learning and Python. It uses the K-Nearest Neighbors (KNN) algorithm to predict digits from images.

## Technologies Used

* Python
* Scikit-learn
* NumPy
* Matplotlib
* Pillow

## Algorithm

**K-Nearest Neighbors (KNN)**

KNN is a supervised machine learning algorithm that predicts a digit by comparing it with similar examples from the training dataset.

## Features

* Recognizes handwritten digits from 0 to 9.
* Trains a machine learning model using the built-in handwritten digits dataset.
* Displays model accuracy.
* Predicts digits from sample images.
* Processes handwritten images using Pillow.

## Installation and How to Run

### 1. Install Python

Install Python on your computer.

### 2. Clone the Repository

```bash
git clone https://github.com/akahitblah2006/Handwritten-Character-Recognition1.git
```

### 3. Open the Project Folder

```bash
cd Handwritten-Character-Recognition1
```

### 4. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 5. Run the Project

```bash
python digit.py
```

**Note:** The code currently loads `seven.png` from the Desktop. To test your own handwritten digit, update the image path in `digit.py`.

## Project Purpose

The purpose of this project is to understand machine learning classification, image preprocessing, and handwritten digit recognition using Python.
