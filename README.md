# Handwritten Character Recognition

## About the Project

This project recognizes handwritten digits using Machine Learning and Python. It predicts the digit written in an image.

## Technologies Used

* Python
* Scikit-learn
* NumPy
* Matplotlib

## Algorithm

K-Nearest Neighbors (KNN)

## Features

* Recognizes handwritten digits from 0 to 9.
* Trains a machine learning model using the handwritten digits dataset.
* Displays predictions and model accuracy.

## How to Run

1. Install Python.
2. Install the required libraries:
   `pip install scikit-learn matplotlib numpy`
3. Run the Python file:
   `python digit.py`

## Project Purpose

The purpose of this project is to understand machine learning classification and handwritten digit recognition.
